# 圖片資料夾說明

把你的照片放在對應的資料夾，然後在程式碼裡用 `/assets/images/xxx/檔名.jpg` 引用。

## 📁 profile/
- 個人大頭照（建議 800x800 以上，正方形或直式）
- 例如：`profile/headshot.jpg`

## 📁 belize/
- 貝里斯拍的所有照片
- 例如：`belize/belize-city.jpg`、`belize/temple.jpg`

## 📁 works/
- 作品截圖、設計稿、數位成果
- 例如：`works/report-cover.jpg`

## 注意事項
- 建議壓縮圖片至 1MB 以下（可用 TinyPNG 網站）
- 命名用英文小寫加底線，避免中文檔名
- 支援 .jpg .png .webp 格式
